# iPhone 版英檢口說練習：GitHub Pages 上傳教學

這個資料夾可以直接上傳到 GitHub Pages。完成後，iPhone 就可以用 `https://` 網址開啟，並使用麥克風錄音。

## 第 1 步：建立 GitHub Repository

1. 打開 GitHub：https://github.com
2. 登入帳號
3. 按右上角 `+`
4. 選 `New repository`
5. Repository name 可輸入：
   `gept-speaking-practice`
6. 選 `Public`
7. 按 `Create repository`

## 第 2 步：上傳檔案

進入剛建立的 repository 後：

1. 按 `uploading an existing file`
2. 把這個資料夾裡的檔案拖進去：
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.json`
   - `.nojekyll`
3. 按下面的 `Commit changes`

注意：請上傳「檔案本身」，不要只上傳整個資料夾。

## 第 3 步：開啟 GitHub Pages

1. 到 repository 上方按 `Settings`
2. 左邊選 `Pages`
3. Source 選 `Deploy from a branch`
4. Branch 選 `main`
5. Folder 選 `/ root`
6. 按 `Save`

## 第 4 步：取得網址

等 1 到 3 分鐘後，GitHub Pages 會產生網址，通常像這樣：

`https://你的帳號.github.io/gept-speaking-practice/`

用 iPhone Safari 開啟這個網址。

## 第 5 步：iPhone 使用方式

1. 用 Safari 開啟 GitHub Pages 網址
2. 按「● 錄音」
3. 出現麥克風權限時，按「允許」
4. 說英文
5. 按「■ 停止」
6. 播放錄音檢查

## 加到 iPhone 主畫面

Safari 下方分享按鈕 → `加入主畫面`。

之後就會像 App 一樣可以從桌面開啟。
